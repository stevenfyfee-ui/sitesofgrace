{% load static %} {% comment %} "On this page" section navigation. Usage: {% include "includes/_section_nav.html" with sections=page.section_nav %} `sections` is a list of {"id": ..., "label": ...}. Renders as a sticky rail in the left margin on wide screens and a sticky chip bar under the header below that -- both driven by the same markup, switched in CSS. Hidden entirely when there is only one section, since a table of contents with one entry is noise. An entry may also carry "children": a second level of {"id", "label"} for sections that contain their own sub-sections (a site page's "Plan Your Visit" and its twelve panels). Children are a display level only -- they are NOT counted by the `sections|length > 1` gate below, because that gate also decides whether the page becomes a two-column grid. A page whose only top-level entry carries twelve children still has one entry, and must not get the rail. Children render only in rail mode; in chip-bar mode the section's own headings are the sub-navigation. {% endcomment %} {% if sections|length > 1 %}
