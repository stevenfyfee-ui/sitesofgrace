{% comment %} A Future Saints search box (future_saints.search). Without JavaScript it is a plain GET form to the results page. With JavaScript it becomes a combobox (the ARIA 1.2 pattern): suggestions filter the cached index in the browser as you type, the arrow keys move through them, Enter opens one (or the results page), Escape closes them, and a polite live region says how many stories were found. Nothing typed is stored or sent anywhere except this site's results page. Usage: {% include "future_saints/includes/_search_box.html" with id="fs-home-search" label="…" mode="home" %} mode: "home" or "page" (choosing a suggestion opens the story), "map" (it selects the story on the map). {% endcomment %}
